## Dependencies

### Critical Path
1. **EPIC-001** must complete first (authentication required for all features)
2. **EPIC-002** depends on EPIC-001 (need user accounts for Jira OAuth)
3. **EPIC-003** depends on EPIC-001 (need users to create test cases)
4. **EPIC-004** depends on EPIC-003 (evidence attached to test cases)
5. **EPIC-005** can run parallel with EPIC-003/004 (infrastructure)
6. **EPIC-006** depends on EPIC-003 (need test cases to export)
7. **EPIC-007** can start after EPIC-001 (subscription independent of features)

### Parallel Work Opportunities
- EPIC-005 (offline mode) + EPIC-003 (test cases) → Different devs
- EPIC-007 (subscriptions) + EPIC-002 (Jira) → Different devs
- EPIC-006 (exports) can start when EPIC-003 is 50% done

## Risk Mitigation

**High-Risk Stories (5+ points):**
- STORY-006: Jira OAuth (complex, external dependency)
- STORY-009: Bidirectional sync (data conflicts, API reliability)
- STORY-012: Rich HTML editor (XSS security, UX complexity)
- STORY-015: Decision tables (combinatorial explosion)
- STORY-025: Auto-save local (filesystem permissions, OS differences)
- STORY-027: Offline mode (sync conflicts, IndexedDB complexity)
- STORY-028: Offline sync (conflict resolution, data integrity)
- STORY-030: PDF generation (layout, image handling)
- STORY-037: Stripe integration (PCI compliance, webhooks)

**Mitigation Strategy:**
- Spike stories in Sprint 0 for Jira OAuth and offline mode
- Weekly demos to validate UX assumptions
- Early integration tests for Stripe (sandbox mode)
